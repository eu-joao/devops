# Skills disponíveis

As skills deste diretório padronizam tarefas recorrentes de contribuição e revisão.

| Skill | Quando usar |
|---|---|
| [criar-issue](criar-issue/SKILL.md) | Redigir, melhorar ou criar issues |
| [commit-push-pr](commit-push-pr/SKILL.md) | Organizar commits, push e criação de PR quando solicitado |
| [estilo-de-contribuicao](estilo-de-contribuicao/SKILL.md) | Redigir descrições de PR e explicar o fluxo Git |
| [revisar-pr](revisar-pr/SKILL.md) | Revisar PRs de forma somente leitura |
| [validar-e-acompanhar-ci](validar-e-acompanhar-ci/SKILL.md) | Escolher verificações e acompanhar os checks da CI |

As skills foram generalizadas a partir de práticas usadas em projetos consumidores. Instruções que dependem de estrutura, ferramentas ou ambiente específicos devem permanecer no repositório correspondente.

A skill de execução do projeto em Codespaces não foi importada porque depende de scripts, serviços e portas específicos de um projeto.
